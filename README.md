# IT Support Portfolio – Rafael Ramires

This repository showcases practical documentation and small scripts related to IT Support and Technical Support activities.
The focus is on troubleshooting, user support, clear documentation, and basic system checks.

This portfolio is designed to demonstrate organization, problem-solving, and communication skills commonly required in IT Support and Help Desk roles.

---

## 🔧 Areas Covered

* Hardware and peripheral troubleshooting
* Network and connectivity issues
* Basic operating system checks
* User onboarding and technical documentation
* Security and good digital practices
* Windows troubleshooting and system recovery
* Cloud backup and Microsoft 365 support
* Security-aware escalation
* Accessibility-aware user support

---

## 📁 Repository Structure

* **troubleshooting-guides/**
  Step-by-step guides for common IT support issues (Wi-Fi, printers, basic system problems).

* **documentation/**
  User-oriented documentation, onboarding guides, and basic IT procedures.

* **scripts/**
  Simple scripts used to collect system or network information for troubleshooting purposes.

* **case-studies/**
  Anonymized real-world support scenarios covering diagnosis, resolution, verification, and lessons learned.
